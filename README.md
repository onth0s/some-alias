# some-alias

Personal PowerShell profile — custom aliases and utility functions for daily use.

## Contents

- `Microsoft.PowerShell_profile.ps1` — main profile with `gotp`, `stp`, `gp`, `yt`, `op`, etc.
- `profile.ps1` — conda-initialized profile (all-session)
- `.gitignore`

## Functions

| Alias | Description |
|-------|-------------|
| `gotp` | `cd` to a path copied to clipboard |
| `stp` | Open path from clipboard in Explorer |
| `gp` | Copy a path to clipboard (arg or cwd) |
| `yt` | Download audio/video with yt-dlp |
| `op` | Launch opencode |
| `sf` | sempath find |
| `HH` | Hermes gateway |
| `uprof` | Reload profile |
